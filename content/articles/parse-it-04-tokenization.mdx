## Continuation

Till now, we have:

```jsx
['3', '*', '(', '9', '+', '5', ')', '+', '45']
```

But here’s something we know, yet the computer doesn’t: The Essence.

We know that `3` is a number, `(` is a parenthesis and `+` is an operator. But the computer… it has no idea. So, let’s fix that!


And that brings us to the topic, **tokenization.**

## So what is tokenization?

It is basically the process of assigning meaning to these pieces, essentially categorizing them. 

> **A token is a piece of an expression together with information about what that piece means.**

Let’s list out what type of tokens we would have. For our program, we’ll basically have these:

- Numbers
- Operators
- Parenthesis, left & right

That is basically it. For this project, we won’t dive into nested braces. 

## Structuring

Let’s define what a tokens should look like. As I mentioned, tokens are basically classifications of the pre-existing data. You must remember, **tokens do not lose data, they get more of it.** So, `45` is not just `NUMBER`, but it is `NUMBER, 45`. In this way, we can structure our tokens are pieces having two information: type and value. For that, let’s use **objects.**

### Objects

But, what are objects? **Objects are basically “key-value pairs”.** An example would be an object `student` as follows:

```jsx
const student = {
	name: 'Neon',
	class: 10,
	isPassing: false
}
```

Here, `student` is an object with 3 keys: `name`, `class`, and `isPassing`. Each key has a value, which could be of various types. Here, we see strings, numbers and even boolean (true/false). This is why they’re called “key-value pairs”. Note that an object must have unique keys. You cannot have two keys named `name` inside `student`. The syntax for accessing the key is `<Object>.<key>` . So to access `name`, we’d do `student.name`.

That’s all you need to know about objects :D

### The token object

So using what we’ve learned, let’s design the object for the token. Since a token must have two things, type and value, let’s define them:

```jsx
const token = {
	type: ...
	value: ...
```

So an example token for `+` would be:

```jsx
{ type: 'operator', value: '+' }
```

And… that’s tokenization! if we repeat that for all the elements of our initial array, we’ll get something like this:

```jsx
[
  { type: "number", value: "3" },
  { type: "operator", value: "*" },
  { type: "left-paren", value: "(" },
  { type: "number", value: "9" },
  { type: "operator", value: "+" },
  { type: "number", value: "5" },
  { type: "right-paren", value: ")" },
  { type: "operator", value: "+" },
  { type: "number", value: "45" }
]
```

So this the exactly the point of this module. **To convert an array of pieces into a well-defined array of token.**

#### Hint 5

<BlurredReveal>
Loop through every piece and determine its type.

A structure like this should get you started:

```js
function tokenize(pieces) {
  const tokens = [];

  for (const piece of pieces) {
    let type;

    // Figure out what type `piece` is...

    tokens.push({
      type,
      value: piece
    });
  }

  return tokens;
}
```

Now fill in the part where you determine `type`.

You can check for:

```js

")"
"+"
"-"
"*"
"/"
```

and finally, check whether the piece is a number.
