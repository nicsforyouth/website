### String vs. Number

Mini detail if you noticed, in the above tokens, the '32' is a string while 20 is a number, can you figure out why that is?

It is because when we multiplied 5 and 4 to get 20 in the first algorithm, `5` and `4` were both strings. In standard practice you can't multiply strings and that, but JavaScript is smart enough to recognize that the string is in fact a number and it converts the datatype on it's own. This, however, will not work on addition as `'4' + '5'` would give you `'45'` instead of `9`.

So it is a good idea to convert all values to numbers before processing them, even for the multiplications and divisions. There are a few ways to do that, but the simplest would be using the `Number()` constructor. So, `Number('45')` would give us `45`, and `Number('nics')` would give us `NaN` (Not a Number)

### The solution

Here's *my* solution. Yours doesn't have to be the same as this, it just needs to work.

```js
const new_tokens = [
  { type: 'number', value: '32' },
  { type: 'operator', value: '+' },
  { type: 'number', value: 20 }
]
let result = Number(new_tokens[0].value)

for let (i = 1; i < new_tokens.length; i+=2) {
  const operator = tokens[i];
  const number = Number(tokens[i + 1]);

  if (operator === "+") {
    result += number;
  } else if (operator === "-") {
    result -= number;
  }
}
```

Notice what's going on? We're initializing the loop from 1, and `i` is increasing by two. Why is that?

So first, we know that the first token will always be a number. So we can just set that as the initial value and start the loop from the 2nd token. 

We also know that after each number, there must be an operator, and after each operator there must be a number. Hence, number and operator occur alternatively. Therefore, we can loop by jumping one token to only loop over the numbers! This cuts our time taken in half!

## YAYYYYYYY!!!!!!

Well, there we go! Now let's put it all together and make a functional script, where the input is a mathematical expression (string) and the output would be its evaluation.

```
function splitExpr(string) {
  const splitted = string.split('').filter(c => c != ' ') // outputs: 3,*,(,9,+,5),+,4,5

  const pieces = []
  let current = ''

  for (let i = 0; i < splitted.length; i++) {
    if (splitted[i] >= '0' && splitted[i] <= '9') {
      current = current + splitted[i]
    } else {
      if (current) {
        pieces.push(current)
        current = ''
      }
      pieces.push(splitted[i])
    }
  }
  if (current) {
    pieces.push(current)
  }
  return pieces;
}

function tokenize(pieces) {
  const tokens = [];

  for (const piece of pieces) {
    let type;

    if (piece >= "0" && piece <= "9") {
      type = "number";
    } else if (
      piece === "+" ||
      piece === "-" ||
      piece === "*" ||
      piece === "/"
    ) {
      type = "operator";
    } else if (piece === "(") {
      type = "left-paren";
    } else if (piece === ")") {
      type = "right-paren";
    }
    tokens.push({
      type,
      value: piece
    });
  }
  return tokens;
}

function evaluate(tokens) {
    
  let new_tokens = []
  for(let i = 0; i < tokens.length; i++) {
    if (tokens[i].value == '*') {
      const result = Number(new_tokens.pop().value) * Number(tokens[i+1].value)
      const number_token = { type: "number", value: result }
      new_tokens.push(number_token)
      i++
    } else if (tokens[i].value == '/') {
      const result = Number(new_tokens.pop().value) / Number(tokens[i+1].value)
      const number_token = { type: "number", value: result }
      new_tokens.push(number_token)
      i++
    } else {
      new_tokens.push(tokens[i])
    }
  }
  
  let result = Number(new_tokens[0].value)

  for (let i = 1; i < new_tokens.length; i+=2) {
    const operator = new_tokens[i].value;
    const number = Number(new_tokens[i + 1].value);
  
    if (operator === "+") {
      result += number;
    } else if (operator === "-") {
      result -= number;
    }
  }
  return result
}

/* Finally, the parser! */
function parse(expression) {
  const pieces = splitExpr(expression)
  const tokens = tokenize(pieces)
  const result = evaluate(tokens)
  return result
} 

const expr = '3 * 4 + 5 * 8 / 2'

console.log(parse(expr))
```
